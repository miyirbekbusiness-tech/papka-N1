# Edith

Oʻzbekcha gapiradigan, hazilkash shaxsiy AI yordamchi (Android). Har bir ishdan oldin sizdan ovoz bilan ruxsat soʻraydi, keyin oʻzi bajaradi.

## Nimalar qila oladi

- Ovoz bilan suhbat (oʻzbek, rus, ingliz tilida tushunadi, oʻzbekcha javob beradi)
- Kontaktdan raqam topib, qoʻngʻiroq qiladi va SMS yuboradi
- Ilovalarni ochadi, ekranni oʻqiydi va boshqa ilovalarda bosadi, yozadi (masalan, Telegram'da xabar)
- Budilnik, taymer, eslatma (eslatmani ovoz chiqarib aytadi)
- Chiroq, ovoz balandligi, batareya holati
- Siz haqingizdagi muhim narsalarni eslab qoladi

Parol, karta raqami va SMS kodlarni hech qachon kiritmaydi, toʻlovni tasdiqlamaydi.

## Oʻrnatish

1. APK'ni yuklab oling: https://github.com/miyirbekbusiness-tech/papka-N1/releases/latest/download/Edith.apk
2. Faylni oching. Telefon "nomaʼlum manbalar"dan oʻrnatishga ruxsat soʻrasa, ruxsat bering.
3. Edith'ni oching va kartadagi uchta tugmani bosing:
   - **Ruxsatlar**: mikrofon, qoʻngʻiroq, SMS, kontaktlar, bildirishnomalar
   - **Ekran boshqaruvi**: Maxsus imkoniyatlar → Edith ekran boshqaruvi → yoqish. "Cheklangan sozlama" chiqsa: Ilova sozlamalari → ⋮ → "Cheklangan sozlamalarga ruxsat berish"
   - **API kalit**: Gemini (bepul limiti bor) yoki Claude kalitini kiriting

## API kalit olish

- Gemini: https://aistudio.google.com/apikey → Create API key → nusxalab Edith sozlamalariga qoʻying
- Claude: https://console.anthropic.com/settings/keys (pullik)

## Yangilash

Kod `main` tarmogʻiga yuborilganda GitHub Actions yangi APK yigʻadi. Yuqoridagi havoladan yangisini yuklab, ustidan oʻrnating: maʼlumotlaringiz saqlanadi.
